# Retail Analytics and Tableau Dashboard

## Project Overview

This project analyses retail sales data using Tableau to transform transactional data into strategic business insights. The analysis examines sales performance, customer segments, product performance, geographical trends and operational delivery patterns.

## Dataset

The analysis uses the Superstore Sales Dataset by Sahoo, accessed through Kaggle.

## Tableau Dashboards

The Tableau workbook contains three interactive dashboards:

* **Executive Overview** – overall sales KPIs, sales trends, regional performance and category analysis.
* **Customer & Product Performance** – customer segments, customer value, product performance and top/bottom products.
* **Regional & Operational Insights** – geographical performance, regional trends, lower-performing states and shipping performance.

## Key Areas of Analysis

* Overall and seasonal sales performance
* Product and category performance
* Customer segment and customer value analysis
* Regional and state-level performance
* Shipping and operational performance
* Interactive Tableau parameters and dashboard filter actions
